Findings

Flow draws the workflow of a user interface: its screens at any size, the decisions between them and what takes the user from one to the next. It checks the workflow as you draw.

Runs in your browser. Nothing you add here is uploaded, and the addresses you save as sources are only links: Flow never opens them itself.

The file format is published: docs/FORMAT.md

Screens: Add a screen from the left, then select it to add text, buttons and inputs to it.

Links: Select a stop and drag the blue arrow beside it onto another. Select the link to write what the user does and under which condition.

Decisions: A decision is a question the system answers. Give it one branch per answer.

Sizes: A screen can have several sizes. Its links belong to the screen, so the workflow is drawn once.

Flow view: Shows every screen as a card, laid out from the links.

Walk: Lists every way from one stop to another.

Play: Clicks through the workflow from the start.

Test: Add a live address (staging, say) and give screens their path on it. Flow lists every way from the start to an end as a test case. Run one: open each real screen in another tab and say whether it is as drawn.

Export: File, Export gives the whole workflow, the selected screens, one marked way or one screen, as a document that merges back, pictures, a storyboard, a report, a copy sheet or a sealed link.

Live: On a Flow server, File, Live starts a room: everyone with its link works on the workflow at once, and sees where the others point. The server only passes on what the browsers have encrypted.

Your workflows: Keeps workflows in this browser, saving themselves on every change.

Languages: Give elements a dictionary key and load the interface's dictionaries (es.json and so on) to show the whole workflow in another language. This is separate from the language of Flow itself.

Blocks and styles: A block is drawn once and placed on many screens; a style is a named colour or text size. Change either and everything that uses it follows.

Select several: Hold Shift and click, or hold Shift and drag a box. Then move, line up, space out, duplicate or delete them together.

Move around: Drag the background, scroll to pan, and hold Ctrl while scrolling to zoom. On a touch screen, pinch with two fingers.

Keys: Delete removes the selection, the arrows move it, Ctrl+D duplicates it, Ctrl+A selects all, Ctrl+Z undoes, Ctrl+S saves a copy.
